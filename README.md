# KayaBot 🤖

> [🇬🇧 English](README.en.md) | 🇮🇷 فارسی

ربات پایش و ارسال خودکار پروپوزال در سایت [kaya.ir](https://kaya.ir).

این ربات با استفاده از Selenium و Chrome Headless، وارد حساب کاربری شما می‌شود،
لیست پروژه‌های تازه منتشرشده را بررسی می‌کند و برای پروژه‌های واجد شرایط
به‌صورت خودکار پروپوزال ارسال می‌کند.

---

## ✨ امکانات

- **ورود با کوکی**: کوکی‌های ورود یک‌بار ذخیره و تا ۳۰ روز مجدداً استفاده می‌شوند (دیتابیس SQLite).
- **پایش خودکار**: هر چند دقیقه یک‌بار صفحه پروژه‌ها را رفرش و پروژه‌های جدید را شناسایی می‌کند.
- **فیلتر کشور**: پروژه‌های ثبت‌شده از کشورهای تعیین‌شده نادیده گرفته می‌شوند.
- **قیمت هوشمند**: محدوده قیمت (مثل `250 - 300`) را خوانده و **میانگین** آن را در فیلد قیمت پروپوزال وارد می‌کند.
- **پروپوزال خودکار**: قیمت، زمان تحویل و متن توضیحات را پر کرده و دکمه ارسال را می‌زند.
- **تشخیص پروژه تکراری**: پروژه‌هایی که قبلاً برایشان پروپوزال رفته دوباره باز نمی‌شوند.
- **حالت Stealth**: اسکریپت‌هایی برای کاهش شناسایی ربات بودن مرورگر.
- **لاگ کامل**: رویدادها هم در کنسول و هم در فایل `kaya_monitor.log` ثبت می‌شوند.

## 🔧 پیکربندی

### ۱. اطلاعات ورود

اطلاعات حساب از **متغیرهای محیطی** خوانده می‌شود، پس رمز عبور هرگز داخل کد قرار نمی‌گیرد.
کلید رمزنگاری کوکی‌ها هم باید جداگانه ساخته شود:

```bash
# ساخت کلید رمزنگاری (یک‌بار)
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

Linux / macOS:

```bash
export KAYA_USERNAME="your_username"   # شماره موبایل یا ایمیل حساب
export KAYA_PASSWORD="your_password"
export KAYA_COOKIE_KEY="<کلید ساخته‌شده در بالا>"
```

Windows (PowerShell):

```powershell
$env:KAYA_USERNAME = "your_username"
$env:KAYA_PASSWORD = "your_password"
$env:KAYA_COOKIE_KEY = "<کلید ساخته‌شده در بالا>"
```

> ℹ️ اگر این متغیرها تنظیم نشده باشند، ربات با خطای واضح متوقف می‌شود.
> کوکی‌های نشست با `KAYA_COOKIE_KEY` رمزنگاری می‌شوند و فایل `kaya.db` فقط به‌صورت رمزشده روی دیسک نوشته می‌شود.
> اگر کلید را عوض کنید، کوکی‌های قبلی خوانده نمی‌شوند و ربات یک ورود تازه انجام می‌دهد.

### متغیرهای اختیاری

| متغیر | پیش‌فرض | توضیح |
|-------|---------|-------|
| `KAYA_DEBUG` | `false` | اجرای مرورگر با پنجره قابل‌مشاهده (برای عیب‌یابی) |
| `KAYA_DEBUG_ARTIFACTS` | `false` | ذخیره اسکرین‌شات صفحه‌های احرازشده هنگام خطا |
| `KAYA_CHECK_INTERVAL` | `5` | فاصله بررسی پروژه‌ها به دقیقه |
| `KAYA_LOG_LEVEL` | `INFO` | سطح لاگ (`DEBUG` برای جزئیات بیشتر) |
| `KAYA_NO_SANDBOX` | `false` | غیرفعال‌کردن sandbox کروم — فقط داخل کانتینر با کاربر root |

> ⚠️ اسکرین‌شات‌های دیباگ ممکن است اطلاعات حساب شما را نشان دهند؛ فقط در صورت نیاز موقت آن را روشن کنید.

### ۲. آدرس پروژه‌ها

```python
self.target_url = "https://kaya.ir/projects/jobs/17"
```

### ۳. کشورهای حذف‌شده

```python
self.excluded_countries = ['India', 'Pakistan', 'Bangladesh']
```

### ۴. متن پروپوزال

متن پیشنهادی خود را در فایل [`descriptions.txt`](descriptions.txt) بنویسید.
(نسخه پیش‌فرض شامل معرفی، تخفیف ۲۰٪ ویژه پروژه اول، و دعوت به گفتگوست.)

### ۵. بازه زمانی بررسی

در انتهای `main.py`:

```python
monitor.monitor_new_projects(check_interval=5)  # هر ۵ دقیقه یک‌بار
```

## 📌 نکات

- **اولین اجرا**: مرورگر باز می‌شود و باید ورود را انجام دهید تا کوکی‌ها ذخیره شوند.
- زمان ارسال به‌صورت **دقیقه‌ای** روی همان روز تفسیر می‌شود؛ اگر ساعت پروژه از زمان فعلی جلوتر باشد، یک روز قبل در نظر گرفته می‌شود.
- اگر کوکی‌ها منقضی شوند، ربات به‌صورت خودکار به ورود دستی برمی‌گردد.
- ربات در حالت `debug=True` اجرا می‌شود؛ برای اجرای بدون پنجره آن را `False` کنید.
